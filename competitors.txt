# Competitor product URLs - one per line.
#
# Two formats are accepted:
#   https://www.example.com/products/blue-widget
#   Example Co | https://www.example.com/products/blue-widget
#
# The second form lets you set the competitor name yourself. Without it,
# the name is taken from the website address (example.com -> Example).
#
# Lines starting with # are ignored, so you can park a URL here without
# deleting it. Blank lines are ignored too.
#
# --- Paste your URLs below this line ---


# ----------------------------------------------------------------------
# CATEGORY PAGES
#
# A line can be a single product page OR a whole category / shop page.
# You do not have to say which - it is worked out from the page itself.
#
# A category page produces one row PER PRODUCT on it, and each row keeps
# that product's own link. One URL can replace a long list, and products
# the competitor adds to that category start appearing on their own.
#
# If a category page is misread as a single product, force it:
#     list:https://example-shop.com/collections/all
#
# Only the FIRST page of a category is read. For a paginated shop, list
# each page, or use a "show all" URL if the shop has one.
#
# Example - remove the # to track all 16 products on it:
# list:https://www.scrapingcourse.com/ecommerce/
# ----------------------------------------------------------------------

list:https://www.scrapingcourse.com/ecommerce/
