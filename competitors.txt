# Competitor pages to check - one per line.
#
# ---------------------------------------------------------------------------
# THE BASICS
#
#   https://www.example.com/products/blue-widget
#       One product page -> one row.
#
#   Example Co | https://www.example.com/products/blue-widget
#       Same, with the competitor name set by you. Without it, the name
#       comes from the web address.
#
# ---------------------------------------------------------------------------
# TWO OPTIONAL WORDS BEFORE THE ADDRESS
#
#   variants:   one row for EVERY variant (each size, colour, grind...),
#               each with its own price and stock. Without it, the product
#               is one row.
#
#   list:       read the page as a category page (a grid of products).
#               Usually worked out automatically; use this if a category
#               page is read as a single product.
#
# They combine, in either order:
#
#   variants:https://www.example.com/products/blue-widget
#       every variant of one product
#
#   list:https://www.example.com/collections/all
#       one row per product on the category page (fast - one page visit)
#
#   list:variants:https://www.example.com/collections/all
#       every variant of every product on the category page. Opens each
#       product's page, so it takes one visit per product.
#
#   Example Co | variants:https://www.example.com/products/blue-widget
#       works with a name too
#
# Worth knowing: without "variants:", a product sold in several sizes gets
# its stock from the shop's headline data, which can say "out of stock"
# while some sizes are available. Use "variants:" where stock matters.
#
# ---------------------------------------------------------------------------
# Lines starting with # are ignored, so you can park a URL here without
# deleting it. Blank lines are ignored too. Only the FIRST page of a
# category is read; for a paginated shop, list each page.
# ---------------------------------------------------------------------------
